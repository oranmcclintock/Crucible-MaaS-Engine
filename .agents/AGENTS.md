# Infrastructure as Code (IaC) Rules for the Deterministic Migration Engine

Any agent working on the infrastructure, deployment, or orchestration of this project MUST adhere to the following rules to ensure compatibility with the target K3s/ArgoCD homelab environment:

## 1. Kubernetes & GitOps First
- **Target Environment:** The target production environment is a K3s Kubernetes cluster managed by ArgoCD GitOps.
- **Manifests over Compose:** While `docker-compose.yml` is acceptable for local rapid prototyping, all production deployment logic MUST be written as standard Kubernetes YAML manifests stored in the `k8s/` directory.

## 2. Strict Security Contexts (Zero Trust)
- **Non-Root Execution:** All Docker containers and Kubernetes Pods must be configured to run as a non-root user (e.g., `USER appuser`, `runAsNonRoot: true`).
- **Capabilities:** Explicitly drop all Linux capabilities (`drop: ["ALL"]`) and set `allowPrivilegeEscalation: false` in the pod's security context.
- **Sandboxing:** Code generated by the engine is untrusted. Be highly paranoid. Never mount host paths or Docker sockets into the executor pod.

## 3. Resource Fencing
- **Limits are Mandatory:** The executor is a highly CPU and Memory-bound multiprocessing Python app. Every Deployment must define strict `resources.requests` and `resources.limits`. Do not allow the pod to burst unbound and starve other critical homelab services.

## 4. Networking Isolation
- **Network Policies:** Always implement a `default-deny` NetworkPolicy for the `migration-engine` namespace.
- **Explicit Egress:** Only explicitly whitelist egress traffic to the internal quarantine database (PostgreSQL) and the specific external legacy database IPs being migrated.

## 5. Storage and Databases
- **No SQLite in K8s:** Do not use SQLite on Kubernetes Persistent Volume Claims (PVCs) for the `quarantine.db` due to file-locking issues with multiple replicas. 
- **Postgres StatefulSets:** Use a dedicated PostgreSQL StatefulSet for the quarantine database, backed by the K3s `local-path` provisioner for bare-metal NVMe performance.
